# ОБОРОТ

Публичный сайт: `/`. Админка: `/admin`. Кабинет скупов: `/pro`.

## Уже работает

- Одностраничный сайт: о нас, скупка, ремонт, витрина и контакты.
- Серверное редактирование текстов, оформления, товаров и фотографий через админку.
- Вход через ChatGPT, доступ владельца по `SITE_ADMIN_EMAIL`.
- Кабинет с личными карточками предложений, расходами, расчётной маржой, чеклистом, вопросами продавцу, решениями и журналом.
- Ручная выдача и отзыв доступа партнёрам по email и сроку. Запросы проверяют срок на сервере.
- Отправка карточки владельцем в Telegram после настройки сервера.

Маржа является расчётом по введённым владельцем суммам, а не оценкой рыночной цены. Вопросы продавцу — шаблон; факты о ремонте и дефектах требуют проверки.

## Серверные настройки

Секреты задаются в runtime-настройках Sites и не попадают в исходники:

- `SITE_ADMIN_EMAIL`: email владельца, входящего через ChatGPT (настроен ранее).
- `CONTACT_RATE_SALT`: секрет защиты открытия номера (настроен ранее).
- `TELEGRAM_BOT_TOKEN`: токен бота из BotFather.
- `TELEGRAM_CHAT_ID`: целевой чат владельца; сначала нужно запустить бота.

После изменения runtime-настроек необходима публикация версии для применения. Проверка конфигурации не означает проверку доставки: тестовую отправку выполняет владелец из кабинета.

## Что требуется для автоматического скупа

1. Регион, радиус, модели, память, бюджет, минимальная маржа и исключаемые дефекты.
2. Подтверждённый источник чужих объявлений. API Авито нельзя считать универсальным поиском рынка без проверки конкретного кабинета и разрешений. Доступные описания Messenger относятся к существующим чатам; первый контакт требует отдельного подтверждения возможностей.
3. Серверный адаптер источника, дедупликация, планировщик и очередь заданий с журналом попыток. Текущий чат ChatGPT не работает фоновым монитором после окончания сессии.
4. Подключение модели через серверный API, правила общения, лимиты сообщений и условия остановки. Сначала полезно проверять черновики. Скрытые дефекты и историю ремонта нельзя выводить как установленные факты из одного объявления.
5. Telegram webhook с проверкой секрета и разрешённого chat_id для решений из бота. Текущая версия отправляет карточку; интерактивные ответы из Telegram ещё не подключены.
6. Для автоматической платной подписки: цена, период, провайдер оплаты, проверка подписанного webhook, идемпотентность и отзыв прав. Сейчас доступ выдаётся вручную; имитации оплаты нет.

Автосбор, автоматическая переписка, рыночная оценка моделью и фоновая доставка сейчас не включены. Состояние подключения показано в кабинете.

## Проверка и выпуск

`npm run install:ci`, `npx tsc --noEmit`, `npm run build`. Изменения схемы добавляются новой миграцией через `npm run db:generate`; прежние миграции неизменны. Публикация включает `dist/.openai`, `dist/server`, `dist/client` и новые SQL-миграции.

В этой среде отсутствуют установленный Sites source-helper и инструмент `cua_repl.js`. Для исходников используется Git с краткосрочным credential только в памяти процесса; сборка выполняется существующими скриптами репозитория. Браузерная визуальная проверка в этой сессии недоступна.
