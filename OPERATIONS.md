# ОБОРОТ

Публичный сайт: `/`. Админка: `/admin`.

## Уже работает

- Одностраничный сайт: о нас, скупка, ремонт, витрина и контакты.
- Серверное редактирование текстов, оформления, товаров и фотографий через админку.
- Вход через ChatGPT, доступ владельца по `SITE_ADMIN_EMAIL`.
## Серверные настройки

Секреты задаются в runtime-настройках Sites и не попадают в исходники:

- `SITE_ADMIN_EMAIL`: email владельца, входящего через ChatGPT (настроен ранее).
- `CONTACT_RATE_SALT`: секрет защиты открытия номера (настроен ранее).
После изменения runtime-настроек необходима публикация версии для применения.

Кабинет партнёров и серверные операции с его карточками удалены. Старые таблицы и миграции сохранены для целостности истории базы данных; приложение их не использует.

## Проверка и выпуск

`npm run install:ci`, `npx tsc --noEmit`, `npm run build`. Изменения схемы добавляются новой миграцией через `npm run db:generate`; прежние миграции неизменны. Публикация включает `dist/.openai`, `dist/server`, `dist/client` и новые SQL-миграции.

В этой среде отсутствуют установленный Sites source-helper и инструмент `cua_repl.js`. Для исходников используется Git с краткосрочным credential только в памяти процесса; сборка выполняется существующими скриптами репозитория. Браузерная визуальная проверка в этой сессии недоступна.
