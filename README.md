# ОБОРОТ

Лендинг скупки, продажи и ремонта техники. В разделе `/admin` владелец может управлять каталогом, текстами, контактами и палитрой. Вход использует авторизацию ChatGPT Sites. Аккаунт владельца берётся из серверной настройки `SITE_ADMIN_EMAIL`.

Товары и настройки хранятся в базе D1 (`DB`), загруженные фотографии — в R2 (`BUCKET`). Для лимитов показа номера используется серверный ключ `CONTACT_RATE_SALT`. Публикация новой версии кода не требует повторно вводить товары или настройки. Контакты добавляются через админку.

Сайт собирается командой `npm run build` после установки зависимостей. Схема базы находится в `drizzle/`. При публикации Sites применяет миграции и разворачивает сервер с подключёнными хранилищами, указанными в `.openai/hosting.json`. Для своего домена добавьте его в Sites и внесите выданные DNS-записи у регистратора.

Витрина реализована на React: адаптивная композиция, системная типографика, плавное появление секций и сцена с прокруткой. Анимации используют Web Animations API и requestAnimationFrame без обновления React на каждом кадре; настройка `prefers-reduced-motion` отключает движение. Общие стили консоли отделены от оформления витрины в `app/storefront.css`.
